# Hypothesis testing

A statistical test evaluates data against a defined null hypothesis under assumptions about sampling and measurement. Select the test before inspecting outcomes where possible, and report the test, sample size, effect size, confidence interval, and p-value when available.

A small p-value does not measure practical importance or the probability that a hypothesis is true. Multiple testing increases false-positive risk. Check assumptions and consider non-parametric alternatives when appropriate. Observational tests do not by themselves establish causal effects.
