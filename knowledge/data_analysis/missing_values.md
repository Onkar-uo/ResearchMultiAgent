# Missing values

Quantify missingness by column and, where useful, by time or subgroup. Missing completely at random, missing at random, and missing not at random imply different risks. Imputation can change distributions and relationships; median or mode filling is a pragmatic baseline, not proof that missingness is harmless.

Preserve an audit of rows changed, values imputed, and methods used. Compare conclusions under plausible alternatives when missingness is material.
