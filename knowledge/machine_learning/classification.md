# Classification

Classification predicts categories. Evaluate using metrics aligned to error costs and class balance: precision, recall, F1, ROC-AUC, PR-AUC, and a confusion matrix can answer different questions. Accuracy alone can be misleading for imbalanced outcomes.

Split data without leakage, tune only on training/validation data, and assess calibration when probabilities drive decisions. A model association is not a causal explanation and may encode historical bias.
