# Regression machine learning

Regression predicts a numeric outcome from features. Keep the target separate from predictors, split data before fitting preprocessing, and use validation data to compare approaches. For time-dependent observations use chronological splits to avoid training on future information.

R-squared measures variance explained relative to a baseline on the evaluated sample; RMSE expresses typical squared-error scale in outcome units. Compare metrics with a simple baseline and consider outliers, target scale, leakage, and generalization. Feature importance indicates predictive utility in a fitted model, not a causal effect.
